# Idevo

**An offline-first personal knowledge library and learning companion for Android.**

Write notes, build your own learning paths, practise with flashcards and quizzes, and track your progress, all on your device.

- **No account and no analytics.** Your data lives on your phone.
- **Works fully offline.** AI and sync are optional extras, both off by default, and both run on a server you own.
- **English and ខ្មែរ.**

Version 0.6.4 is an early build.

### [⬇ Download Idevo (latest release)](https://github.com/hongrinrasmey/Idevo-Downloads/releases/latest)

## Which file?

| File | For |
| --- | --- |
| `idevo-<version>-arm64-v8a.apk` | Most phones |
| `idevo-<version>-armeabi-v7a.apk` | Older 32-bit phones |
| `idevo-<version>-x86_64.apk` | Emulators and x86 devices |

## Install

1. On your Android phone, open the download link above and tap the **arm64-v8a** APK.
2. Your browser may warn that this type of file can harm your phone. Android shows this for every app downloaded outside Google Play. Tap **Download**.
3. Open the file. If Android asks, allow your browser to install apps, then tap **Install**.
4. To update, install the newer APK over the old one. Your data is kept.
